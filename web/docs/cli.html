CLI reference

Every pln command grouped by topic. Same content as pln <command> --help, easier to scan. New to Pollen? Run through the Quickstart first; for the model behind the commands, see Concepts.

Contexts

Most pln commands need to know which daemon they're talking to. Named contexts are the primary mechanism. The reserved name default always resolves to the local daemon at $PLN_DIR; add more to point at remote hosts or alternate state directories. See the Multiple clusters recipe.

Aliases. pln ctx is short for pln context, and use is short for switch. Examples below use the short forms; either works.

pln ctx add <name> <target>

Targets containing @ bind to a remote daemon over SSH; absolute paths bind to a local pln dir. Local named contexts get a free UDP port assigned automatically so they coexist with the default-context daemon without colliding on :60611.

--from <dir|default>
For remote contexts: import an existing admin keypair so this shell can act as admin. Pass a directory, or default to take the keys from $PLN_DIR/keys.
pln ctx add prod root@prod.example.com --from default added context "prod" pln ctx add dev /tmp/pln-dev added context "dev" warning: /tmp/pln-dev does not exist yet; run `pln init` or `pln up` after switching to this context

pln ctx use <name>

Switch the active context. To use a different context for just one command, set PLN_CONTEXT for that invocation:

pln ctx use prod current context: prod PLN_CONTEXT=prod pln status # one-off, active context unchanged

pln ctx ls

List contexts. The active one is marked with * in the CURRENT column.

pln ctx ls NAME TARGET CURRENT default ~/.pln (local) * prod root@prod.example.com dev /tmp/pln-dev :49213

pln ctx rm <name>

Remove a context. For remote contexts whose identity lives under ~/.pln/contexts/<name>/, the per-context dir is also deleted.

pln ctx rm dev removed context "dev"

pln ctx current

Print the active context name only. Useful in shell prompts.

pln ctx current prod

pln ctx show [name] (alias pln ctx whoami)

Print a context's target, identity, capabilities, and grant status (the active context if no name is given). Use it to check why a wire-mode command was refused.

pln ctx show staging context: staging target: pln://edge.example.com:7443 dir: ~/.pln/contexts/staging identity: k7m2q8x4 issuer: a1b9c3d2 status: ok not before: 15 May 2026 09:25 BST rejoin by: 14 Jun 2026 09:25 BST caps: delegate=false admit=false publish=true max_depth=0

rejoin by is the grant deadline: the point past which the grant is dead and the node cannot rejoin on its own. Delegated grants default to a 30-day deadline; admin grants print rejoin by: never (admin grant) and carry no deadline. Before the deadline the grant renews itself automatically against any reachable delegating peer, so a node keeps working with the root offline. When no identity is enrolled the block collapses to identity: none (run `pln join <token>`).

There is no pln renew. Renewal is automatic: the daemon renews on a background loop, and wire-mode contexts renew on the next dial. If a grant passes its rejoin by deadline, recover with a fresh pln invite followed by pln join <token>. See access expired or node degraded and Grants in Concepts.

Per-command override

Three ways to point a single command somewhere other than the active context, without switching it:

$PLN_CONTEXT <name>
Use the named context for this invocation only. Equivalent to pln ctx use scoped to one command.
--dir <path>
State directory. Defaults to ~/.pln, or /var/lib/pln on Linux once pln daemon install has provisioned it. Env PLN_DIR.
-H, --host <user@host>
Tunnel through SSH and run against the remote daemon. Env PLN_HOST.

Lifecycle

Daemon lifecycle verbs live under pln daemon; pln up, pln logs, and pln upgrade are top-level aliases for the same handlers.

pln up (alias pln daemon up)

Start the local node. Foreground by default; -d hands off to launchd (macOS) or systemd (Linux). If no credentials exist, auto-initialises a single-node root cluster.

-d, --detach
Run as background service.
--port <n>
Listening UDP port (default 60611).
--ips <ip,...>
Advertise these IPs to peers.
--public
Hint that this node is publicly reachable, making it a relay candidate. Actual reachability is verified by the mesh via NAT probing.
--name <str>
Human-readable node name.
--metrics
Log metrics and trace output at debug level.
pln up
pln up -d --name relay --public

If the node's grant is no longer valid, the daemon still starts but prints node grant no longer valid — starting in degraded mode; rejoin with `pln join <token>` and runs degraded until an admin peer is reachable or you rejoin. Degraded is the state of a node still serving on a grant whose renewal is failing; it is not a post-deadline grace period. See Grants in Concepts.

pln down (alias pln daemon down)

Stop the background service. State and credentials are preserved.

pln restart (alias pln daemon restart)

Restart the background service. Use after pln set or pln serve to rebind listeners, or after pln props on root to re-issue the root grant from the persisted properties.

pln logs (alias pln daemon logs)

Tail the background daemon's log (Homebrew log on macOS, journalctl on Linux).

-f, --follow
Stream in real time.
-n, --lines <n>
Number of lines (default 50).

Content

pln seed <source> [name]

Publish content to the mesh. The kind is autodetected from the source: .wasm is a workload, a directory is a static site, anything else is a blob (or stdin when source is -). Publishing workloads, static sites, and named blobs requires the publisher capability (or admin, which is a strict superset). Each published resource is a signed record that names the publisher's grant; it stays valid while that grant is within its deadline and not revoked, even after the publisher leaves.

--min-replicas <n>
Workload only. Minimum replicas; default 2. Static sites fan out to every node with static-http enabled; blobs replicate on demand.
--everywhere
Workload only. Place a replica on every node.
--memory, --mem <size>
Workload only. Memory limit (e.g. 64MiB, 1GiB). Default 8MiB; raise it for Go-WASM guests.
--timeout <dur>
Workload only. Per-invocation timeout (e.g. 500ms, 5s).
--allow-prop key=value
Require the caller's grant property to equal value. Repeatable; all clauses must match (AND). Without any policy flag the resource is open to every authenticated peer. See Admission in Concepts.
--public
Permit anonymous callers (no grant) via the canonical gateway URL https://fn.<domain>/<slug>/<name> (workload) or https://blob.<domain>/<slug>/<name> (blob). Mutually exclusive with --allow-prop.
pln seed ./hello.wasm seeded hello (4f3a7c91) pln seed ./echo.wasm --public seeded echo (3a8c7d2e) → https://fn.pln.sh/k7r4z9xa8n2p/echo pln seed ./public my-site seeded my-site (12 files, manifest 3a8c7d2e) pln seed ./big.bin payload seeded payload (e892bca7) cat data | pln seed - b1f9a2d4c5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2

pln unseed <name-or-hash>

Stop publishing content. Resolves the arg against current workloads, sites, and blobs; errors if it matches more than one kind.

pln unseed hello
pln unseed ab12cd34       # by hash prefix

pln fetch <name-or-hash> <dest>

Stream a blob's plaintext bytes from its publisher and write them to <dest>. Pass - as the destination to write to stdout. The local content store is not modified; use pln seed to host a copy on this node.

pln fetch payload ./payload.bin
pln fetch ab12cd34 -

pln call <name-or-hash> <function> [input]

Invoke a WASM function. Routed to the nearest, least-loaded replica via P2C. Input may be the third positional or piped on stdin; output is written raw to stdout.

--timeout <dur>
Overall deadline (default 60s).
--retries <n>
Retry budget for transient overload/unavailability (default 3).
pln call echo echo 'hello world' hello world cat payload.json | pln call hello greet

pln share <name-or-hash>

Mint a signed, time-limited URL authorising anonymous access to a blob (fetch) or workload (invoke). The token carries the resource identity and the publisher's signature; the share-URL gateway verifies both before passing the request through. Publish-tier capability or above; the daemon refuses to sign for resources the caller didn't publish.

--ttl <dur>
Validity window (default 1h).
--gateway <host>
Gateway base DNS (default pln.sh). The URL becomes https://blob.<host>/_/<token> or https://fn.<host>/_/<token>; the _ segment is reserved so it never collides with a publisher slug.
pln share payload https://blob.pln.sh/_/RrkFG...AAAA pln share echo --ttl 24h https://fn.pln.sh/_/RrkFG...AAAA

Networking

pln serve <port> [name]

Register a local TCP (or UDP) port as a mesh service. Requires the publisher capability (or admin) and is persisted to config.yaml. Every register issues a fresh signed record that names the publisher's grant.

--udp
Expose as a UDP service.
--allow-prop key=value
Require the caller's grant property to equal value. Repeatable; all clauses must match (AND). Without any policy flag the service is open to every authenticated peer. See Admission in Concepts.
--public
Permit anonymous callers. Mutually exclusive with --allow-prop.
pln serve 8080 api Registered service api on port: 8080 pln serve 5353 dns --udp Registered service dns on port: 5353 pln serve 9000 internal --allow-prop team=backend Registered service internal on port: 9000

pln unserve <port|name>

Unregister a local mesh service. Removes it from config.yaml; open tunnels from peers terminate.

pln unserve api Unregistered service api pln unserve 5353 Unregistered service on port: 5353

pln connect <service> [provider] [local-port]

Open a local listener forwarding to a remote mesh service. Provider disambiguates when multiple peers serve the same name (use the peer-id prefix from pln status). Persisted to config.yaml.

pln connect api forwarding localhost:8080 -> api (198.51.100.10:8080) pln connect api ab12 9090 forwarding localhost:9090 -> api (198.51.100.10:8080)

pln disconnect <service|local-port> [provider]

Tear down a local tunnel. Identify by service name or local port. Removes from config.yaml.

pln disconnect api disconnected localhost:8080 from api (198.51.100.10:8080)

Cluster

pln init

Initialise a new root cluster on this node. Idempotent if already initialised as root.

--prop key=val
Root node properties; baked into the root grant and persisted to config.yaml. Update later with pln props and restart.
pln init initialized root cluster root_pub: 7c9a4f8d3e2b1c5a6d8e9f0a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c cluster_id: a1b2c3d4e5f6789a1b2c3d4e5f6789a1b2c3d4e5f6789a1b2c3d4e5f6789a1b2 pln init --prop role=primary --prop region=eu

pln join <token>

Enrol this node into the cluster the token was minted for. Writes credentials and exits; pass --up to also start the daemon. This is also the recovery path: if a node's grant has passed its deadline, mint a fresh token with pln invite and run pln join again.

-u, --up
Start the daemon after enrolment.
--public
Hint that this node is publicly reachable, making it a relay candidate. Actual reachability is verified by the mesh via NAT probing.
pln join eyJhbG...AAAA credentials enrolled; run `pln up -d` to start the node pln join eyJhbG...AAAA --up credentials enrolled; starting daemon

Once enrolled, the grant renews itself automatically before its deadline against any reachable delegating peer, so there is no pln renew command and a node keeps working with the root offline. pln join is only needed for first enrolment or to recover a grant that has already passed its deadline. See Grants in Concepts.

pln invite [subject-pub]

Mint a signed invite token. Pass to pln join. Requires admin capability on the issuing node. The default tier is leaf (consume only); pass --publisher, --workspace or --admin to widen. The token is printed raw with no trailing newline, so it pipes cleanly.

--subject <hex>
Bind to a specific node public key. Without it, the token admits any node.
--ttl <dur>
Token validity (default 5m).
--expire-after <dur>
Override the deadline on the issued grant (the point past which the node cannot rejoin on its own). Delegated grants default to a 30-day deadline.
--publisher
Mint the joiner's grant with publisher capability so it can publish workloads, blobs, services, and static sites.
--workspace
Mint the joiner's grant as a workspace-admin: founds a workspace, may delegate within it, sees its chain ancestors and its own subtree. Mutually exclusive with --publisher and --admin.
--admin
Mint the joiner's grant with admin capabilities (delegate, admit, publish, cluster-wide visibility). The issuer must itself be admin-capable. Mutually exclusive with --publisher and --workspace.
--prop key=val
Properties baked into the joining peer's grant. Repeatable; accepts key=value, a JSON object, or - to read JSON from stdin.
--max-functions <n>
Cap on workloads the joining peer may publish. Default 0 (no cap).
--max-blobs <n>
Cap on blobs the joining peer may publish. Default 0 (no cap).
--max-sites <n>
Cap on static sites the joining peer may publish. Default 0 (no cap). Budgets are a count of published resources; there are no byte or traffic quotas. The same flags are accepted by pln grant for a peer that has already joined.
pln invite --ttl 30m --prop role=worker
pln invite --publisher --subject $(ssh worker pln id)
pln invite --publisher --max-functions 10 --max-blobs 50 --max-sites 2
pln invite --admin --subject $(ssh relay pln id)

pln grant <peer-id>

Re-grant a connected peer with fresh capabilities. Identify by peer-id prefix. Default tier is leaf. A delegated grant carries a deadline (default 30 days) and renews itself automatically before then; admin grants carry no deadline. The admin mints the grant and pushes it to the peer over the existing mesh connection; the peer verifies, swaps in its own credentials, and gossips the new grant with its own subject signature. Capabilities a peer loses in the process trigger automatic tombstones of any resources the peer had published under those kinds.

--publisher
Grant publisher capability so the peer can publish resources.
--workspace
Promote to workspace-admin: the peer founds a workspace it may delegate within and sees its chain ancestors plus its own subtree. Mutually exclusive with --publisher and --admin.
--admin
Delegate admin authority (so the cluster keeps working with root offline). Mutually exclusive with --publisher and --workspace.
--prop key=value
Grant properties. Repeatable.
--max-functions <n>
Cap on workloads the peer may publish. Default 0 (no cap).
--max-blobs <n>
Cap on blobs the peer may publish. Default 0 (no cap).
--max-sites <n>
Cap on static sites the peer may publish. Default 0 (no cap). Budgets are a count of published resources; there are no byte or traffic quotas.
pln grant ab12cd34 --prop role=lead --prop team=backend upgraded ab12cd34 → leaf pln grant worker1 --publisher --max-functions 10 --max-blobs 50 upgraded 8c4d2f9a → publisher pln grant relay1 --admin upgraded ab12cd34 → admin

When the named peer is a wire-mode tenant with no live daemon, pln grant falls back to printing a subject-pinned invite token; the tenant redeems it with pln join <token> to swap their credentials in place. This is the same path as a first join, just bound to the existing identity. See Grants in Concepts.

pln deny <peer-id>

Revoke a peer's membership and tear down its connections. Identify by peer-id prefix. Cascades to peers admitted by the denied node.

pln deny ab12cd34 denied peer ab12cd34

pln purge

Delete local cluster credentials (including the stored grant at keys/grant.pb), CAS, runtime state, and config. Daemon must be down. Prompts unless --yes.

--include-keys
Also wipe the node identity keys.
--yes
Skip confirmation.
pln purge --yes local state purged

pln bootstrap ssh [name=]<target> ...

Install Pollen, enrol, and start the daemon on each SSH target in parallel. Linux only. Needs SSH as root or with passwordless sudo. Targets may also be piped from stdin (one per line) using -.

--publisher
Issue publisher capability to every enrolled node.
--workspace
Issue workspace-admin capability to every enrolled node. Mutually exclusive with --publisher and --admin.
--admin
Delegate admin authority to every enrolled node. Mutually exclusive with --publisher and --workspace.
--prop key=val
Properties baked into every enrolled node's grant. Repeatable; accepts key=value, a JSON object, or - to read JSON from stdin.
--relay-port <n>
Relay UDP port to advertise (default 60611).
--expire-after <dur>
Override the deadline on every issued grant. Delegated grants default to a 30-day deadline.
--no-up
Skip starting the local daemon after bootstrapping.
pln bootstrap ssh user@host bootstrapping user@host... user@host ok pln bootstrap ssh relay-eu=root@10.0.0.5 relay-us=root@10.0.0.6 --admin pln bootstrap ssh worker=root@10.0.0.7 --publisher echo "media=alice@10.0.0.5" | pln bootstrap ssh -

Inspection

pln status [nodes|services|seeds|static|blobs]

Render an overview of the cluster from this node's perspective. Optionally restrict to a single section.

--wide
Full peer IDs, plus per-peer metrics (CPU, memory, latency, throughput).
--include-offline
Include offline peers, services, and orphaned blobs.

The header shows two chips: cluster health (HEALTHY / DEGRADED / UNHEALTHY) and the local node's capability tier (ADMIN / WORKSPACE / PUBLISHER / LEAF). The tier reflects what this node can do; commands that require a higher tier (e.g. pln grant) fail with a clear error when invoked from below it.

pln status HEALTHY PUBLISHER context: home PEERS NODE STATUS ADDR CPUs CPU MEM TUNNELS LATENCY IN OUT 7c9a4f8d (self) - - 8 2% 18% 1 - - - ab12cd34 direct (public) 198.51.100.10:60611 4 1% 8% 1 12ms 0 0 SEEDS NAME HASH STATUS REPLICAS LOCAL UPTIME hello 4f3a7c91 running 2/2 * 4m temporary access expires in 23d

The last line is the grant's deadline footer. A delegated leaf or publisher grant has a deadline, so it reads temporary access expires in <d> while the grant is valid and temporary access expired — rejoin the cluster or contact a cluster admin once the deadline has passed. Admin and root grants carry no deadline, so this footer does not apply to them.

pln inspect <target>

Drill into a single peer or resource. <target> resolves against the cluster view this node holds: a peer-id hex prefix, a workload or static-site name, a blob name or hash prefix, or a service name (suffixed when several peers serve the same name). Use this when pln status shows the row but you need the underlying grant, properties, telemetry, or publish list.

Node detail is implemented. Resource targets (workloads, static sites, blobs, services) are recognised but currently return resource inspection not yet implemented; use pln status for resource details in the meantime.

pln inspect ab12cd34 NODE name gamer peer-id ab12cd34ef56011223344556677889aabbccddeeff00112233445566778899aa status direct (public) addr 10.0.0.42:7531 tier publisher membership expires in 23d issued by root-admin [d3f9ab12] attributes region eu role worker TELEMETRY cpu 8 cores, 14% mem 8 GiB total, 41% nat easy reachable 3 peers tunnels 2 PUBLISHES services api, dns workloads greeter blobs payload

pln id

Print this node's hex-encoded ed25519 identity public key, with no trailing newline. Pipe-friendly. Used as the --subject of an invite token.

pln invite --subject $(ssh user@host pln id)

pln version

Show binary version, commit, and build date. --short prints only the version string.

pln version version: 0.9.2 commit: 4f3a7c91 date: 2026-05-17 pln version --short 0.9.2

The control wire is versioned and negotiated per dial. If pln and the daemon disagree on the protocol range, the command fails with exactly one of:

pln is out of date: this daemon speaks protocol X-Y but pln supports only up to Z; upgrade pln
the daemon is out of date: it speaks protocol X-Y but pln requires at least Z; upgrade the daemon
the daemon is out of date: it does not support protocol negotiation; upgrade the daemon

Bring both sides onto a compatible build with pln upgrade. See staying current and out of date.

Daemon admin

Operations that act on the daemon binary or its background unit, rather than the running node. Operational lifecycle (up/down/restart/logs) stays at the top level.

pln daemon install

Linux only. Creates the pln system user, state dir, drops the systemd unit, enables it. If invoked via sudo, adds the invoking user to the pln group. Idempotent.

sudo pln daemon install pln daemon installed at /lib/systemd/system/pln.service using /usr/local/bin/pln

pln daemon uninstall

Stop and remove the systemd unit. --purge also wipes /var/lib/pln (irreversible).

--purge
Also wipe /var/lib/pln.
sudo pln daemon uninstall pln daemon uninstalled sudo pln daemon uninstall --purge purged /var/lib/pln

pln upgrade (alias pln daemon upgrade)

Upgrade the local pln binary via the platform package manager: Homebrew on macOS, the install script on Linux. Linux preserves the current install method by default: /usr/local/bin/pln stays on tarball installs; /usr/bin/pln uses distro package-manager detection.

--restart
Bounce the background service after upgrading.
--method
Linux install method override: auto or tarball.
pln upgrade --restart
pln upgrade --method tarball

Config

Daemon config lives in config.yaml. Manual edits while the daemon runs will be overwritten. Use pln set for daemon listener addresses, pln props for the local node's identity properties.

pln set [key] [value]

Set a daemon config value. Run with no args to list keys. Omit the value to apply the default. Restart the daemon to rebind listeners.

http
Prometheus metrics listener (default :9090).
static-http
HTTP listener for static sites (default :8080).
static-http-domain
Public DNS suffix served by the static listener (e.g. pln.sh); enables <name>-<slug>.<domain> routing.
control-tls
TLS+mTLS listener for the public control RPC (e.g. :7443).
gateway
HTTP listener for the anonymous share-URL gateway (e.g. :8088). Route blob.<domain> and fn.<domain> at this listener.
log-level
Verbosity: debug, info, warn, error.
pln set Available keys: control-tls TLS+mTLS address for the public control RPC (e.g. :7443) (default ) gateway HTTP address for the anonymous share-URL gateway (e.g. :8088) (default ) http HTTP address for Prometheus metrics (default :9090) log-level Log verbosity: debug, info, warn, error (default info) static-http HTTP address for serving static sites (default :8080) static-http-domain Public DNS suffix served by the static listener (e.g. pln.sh); enables `<name>-<slug>.<domain>` routing (default ) pln set http :9100 set http=:9100 (run `pln restart` to apply)

pln unset <key>

Clear a daemon config value, restoring default behaviour.

pln unset http unset http (run `pln restart` to apply)

pln props [key=value ...]

List or replace this node's identity properties. Properties are baked into the local grant and surfaced to seeds and admission policy on every call. Local-only; root nodes only (delegated peers receive properties via pln grant or pln invite --prop).

--clear
Remove all properties. Cannot be combined with positional args.

Replace semantics: positional args define the complete set, so any unlisted key is removed. Changes take effect on the next pln up; root re-issues its root grant from the persisted properties on every start, and renewal keeps delegated grants fresh from then on. The trailing hint reads (run `pln restart` to apply) when the daemon socket is active, otherwise (will apply on next `pln up`).

pln props role=primary region=eu pln props role=primary region=eu properties updated (run `pln restart` to apply) pln props --clear properties updated (run `pln restart` to apply) pln props (no properties set)

Exit codes

Non-zero codes let scripts react to common failures without parsing error text.

0
success
1
generic error
3
not found (no peer, blob, or service matches the arg)
4
permission denied (socket perms, sudo required)
5
ambiguous (a prefix matched multiple things)
6
unreachable (daemon down, peer offline, network)
